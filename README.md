### 🎉 What's New in Version 1.0.0

This initial public release introduces the complete 4-layer UES security specification, featured by our flagship **UES-S01 In-Band Psychoacoustic Engine**.

#### 🌟 Key Breakthroughs

* **UES-S01 Acoustic Engine (In-Band Defense):**
  * Solves the fundamental flaw of legacy ultrasound defenses. By injecting adversarial perturbations directly into active human speech formants ($200\text{Hz} - 4000\text{Hz}$), perturbations survive AI $16\text{kHz}$ downsampling and bandpass filtering while remaining clear to human listeners via psychoacoustic dynamic masking.
  * Successfully triggers feature alignment collapse in state-of-the-art Speech-to-Text models (Gemini, Whisper, Wav2Vec2).
* **UES-P01 Visual Defense:**
  * Zlib Level 9 Deflate payload packaging combined with MT19937 PRNG spatial permutation and boundary noise envelopes ($M \times M$).
* **UES-D01 Dynamic Seed Rotation:**
  * UTC epoch-based seed derivation ($\text{Seed}_t$) to prevent crawler replay attacks and long-term dataset aggregation.
* **UES-D02 Spectral Frequency Shifting:**
  * 2D-DCT mid-high frequency coefficient inversion targeting computer vision edge detection and CNN feature extractors.
* **Interactive Web Simulator Workbenches:**
  * Real-time Web Audio API interactive simulator (`ues_s_simulator.html`) allowing users to visualize waveforms, spectrograms, AI feature loss, and export protected `.wav` files directly from their browsers.
